Background & Operational Need
Accurate Digital Elevation Models (DEMs) and Digital Surface Models (DSMs) are fundamental to urban planning, disaster management, and military reconnaissance. Traditionally, elevation data is acquired through stereo-imaging pairs, LiDAR, or Interferometric Synthetic Aperture Radar (InSAR). These approaches can be cost-prohibitive, dependent on specific sensor availability, and computationally intensive. Single-view height estimation offers an agile alternative, but foundational monocular depth models are trained largely on natural egocentric imagery and predict relative depth. When applied to remote sensing, they face domain gaps, structural variations, and a lack of absolute-scale mapping. Converting relative depth into metric elevation remains a critical challenge, alongside the operational need to transform static elevation profiles into interactive 3D assets that can be navigated in real time.
Pipeline Architecture & Description
Develop an end-to-end software pipeline that transforms single-view optical RGB remote-sensing images into high-precision elevation maps. The framework supports dual-modality processing:
  • Non-Georeferenced RGB Imagery (e.g., PNG or JPG): Produces a Relative Digital Surface Model (rDSM) for images without spatial metadata.
  • Georeferenced RGB Imagery (e.g., GeoTIFF): Produces an Absolute Digital Surface Model (DSM) with calibrated metric height values for images containing coordinate-system metadata.
The solution uses a pre-trained monocular depth-estimation backbone to generate initial relative-depth maps. For georeferenced imagery, lower-resolution DEM sources (SRTM / Copernicus 30m) or Ground Control Points (GCPs) map scale-agnostic features to absolute metric elevations. The pipeline projects original optical textures onto the 3D terrain mesh for real-time aerial navigation in Three.js.
Key Implementation Milestones
  • Elevation Extraction: Robust pre-trained monocular depth models (Depth Anything V2, MiDaS DPT) extract structural geometry from single-view optical imagery.
  • Scale Calibration: Automated module converts relative depth to absolute metric height using scene statistics, reference DEMs, and GCP alignment.
  • Visualization Layer: Immersive, real-time rendering engine converting texture and derived elevation maps into a navigable 3D environment with drone flight controls.
Evaluation Criteria & Expected Solution
DSM Accuracy & Validation (50%) Benchmarking RMSE, MAE, NMAD, and LE90 against LiDAR ground truth across urban, alpine, volcanic, and canyon landscapes.
Rendering & Flythrough (50%) Projection accuracy, photorealistic texture mapping, smooth first-person drone navigation, transect slicing, and standalone stability.
Expected Deliverables: Fully integrated elevation estimation module supporting PNG/JPG/GeoTIFF raster exports + interactive 3D flythrough platform with live metric verification audits.
